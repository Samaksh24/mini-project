CivicFix UI refinement update

What changed:
- Added consistent centered page width and responsive spacing to the public complaints page.
- Reduced oversized heading and complaint priority typography; improved card spacing on mobile.
- Made navigation wrap into a horizontally scrollable second row on narrow screens.
- Standardized report and login page headings, container widths, and vertical spacing.
- Added a Week / Months dropdown to the admin Recent report trend chart. Week shows daily counts for the last 7 days; Months shows monthly counts for the last 6 months.
- Backend files and API contracts were not changed.

Install:
1. Back up your existing Frontend/src folder.
2. Copy this archive's Frontend/src folder over your existing Frontend/src folder.
3. Run npm run build in Frontend, then npm run dev.
